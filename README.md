# IEEE PES UTP — Primera versión visual

Esta es la primera maqueta de la página pública. Está hecha con HTML, CSS y JavaScript sin frameworks para que puedas abrirla fácilmente en Visual Studio Code.

## Ver la página
1. Descomprime el archivo ZIP.
2. Abre la carpeta `ieee-pes-utp` en Visual Studio Code.
3. Abre `index.html` en el navegador. Recomendado: usar la extensión **Live Server** de VS Code y hacer clic en **Go Live**.

## Archivos
- `index.html`: estructura y contenido.
- `styles.css`: colores, diseño adaptable y estilos.
- `script.js`: menú móvil.
- `assets/logo-ieee-pes-utp.png`: imagen de identidad compartida.

## Importante
Esta versión es únicamente visual. Todavía no incluye inicio de sesión, base de datos, panel de Eventos/Marketing, publicación real ni sincronización con Google Sheets. Esas funciones se implementarán después de validar el diseño y definir la arquitectura.
